# Fighting Game Combo Book

Guilty Gear -Strive- と Street Fighter 6 のコンボを参照する静的Webアプリです。ゲームを切り替え、GGSTはラムレザル・ブリジット・エルフェルト、SF6は舞・ベガ・ブランカを選べます。

## 使い方

- `index.html` をブラウザーで開き、ゲーム・キャラクターを切り替えます。両方のゲームで「コンボ／起き攻め／連携」を利用できます。SF6の入力はテンキー表記です。
- 「＋ マイコンボ」で選んだコンボだけを自分用に表示できます。選択と追加メモはブラウザー内に保存されます。

## データとファイル

- `index.html` — 画面、ラムレザルとSF6のルート、保存・表示処理
- `roster.js` — 追加キャラクターのルート。画面にはブリジットとエルフェルトだけを表示
- GGSTの起き攻め情報はコンボの登録内容から表示し、追加の起き攻め・連携メモは `${characterId}ReferenceBook` に保存します。
- コンボ選択はゲームごとに異なるキャラクターIDの保存領域を使い、既存のGGST保存キーを維持します。

## 開発方針

コンボ候補はダメージ、難易度、実戦での狙いやすさ、習得負担、共通ルート、コンボ後の起き攻めを総合して選びます。状況別・始動技別に整理し、同じ用途の重複を抑えます。現行版の資料に基づく候補と未検証のルートは区別し、空欄の情報を推測で埋めません。SF6の入力はクラシック操作のテンキー表記です。

変更時は関連する確認を行い、ローカルでコミットします。GitHubへの公開はユーザーが承認した場合に行います。
