# Fighting Game Combo Book

静的なコンボ集Webアプリです。ページ上部の切り替えボタンでGuilty Gear -Strive- と Street Fighter 6を切り替えます。選んだゲームのキャラクター、状況別コンボ、マイコンボだけが表示されます。

## 使い方

- `index.html` をブラウザーで開きます。
- GGST / スト6を切り替え、キャラクターを選択します。
- 「＋ マイコンボ」で自分用の一覧に加え、「マイコンボだけ表示」で整理できます。
- GGSTは「コンボ／起き攻め／連携」を切り替えて参照できます。起き攻めにはコンボに登録済みの情報も表示され、起き攻めと連携はキャラクターごとに追加・編集できます。
- バックアップと復元は選択中のゲーム・キャラクター単位です。

## データ

- GGSTの追加キャラクターは `roster.js`、スト6は `sf6.js` にあります。ラムレザルとソルの既存データは `index.html` に保持しています。
- スト6のコンボ候補はクラシック操作、Year4（2026年8月3日のバトル調整）を基準に、キャラクター別資料へリンクします。資料に基づく候補とゲーム内で確認済みのルートは区別してください。
- 両ゲームのマイコンボはブラウザーのローカル保存領域で独立しています。GGSTの既存保存キーは変更していません。
- GGSTの起き攻め・連携メモは `${characterId}ReferenceBook` キーに保存します。GGSTのバックアップJSONにはこれらのメモも含まれます。

## 主なファイル

- `index.html` — 画面、ラムレザル／ソルのデータ、保存・表示処理
- `roster.js` — GGSTの追加キャラクター
- `sf6.js` — スト6のキャラクター一覧とコンボ候補
