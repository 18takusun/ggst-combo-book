# GGST Combo Book

Guilty Gear -Strive- のコンボ・起き攻め・連携を参照する静的Webアプリです。現在の対象キャラクターはラムレザル、ブリジット、エルフェルトです。

## 使い方

- `index.html` をブラウザーで開き、キャラクターと「コンボ／起き攻め／連携」を切り替えます。
- 「＋ マイコンボ」で選んだコンボだけを自分用に表示できます。選択と追加メモはブラウザー内に保存されます。

## データとファイル

- `index.html` — 画面、ラムレザルのルート、保存・表示処理
- `roster.js` — 追加キャラクターのルート。画面にはブリジットとエルフェルトだけを表示
- 起き攻め情報はコンボの登録内容から表示し、追加の起き攻め・連携メモは `${characterId}ReferenceBook` に保存します。

## 開発方針

コンボ候補はダメージ、難易度、実戦での狙いやすさ、習得負担、共通ルート、コンボ後の起き攻めを総合して選びます。状況別・始動技別に整理し、同じ用途の重複を抑えます。現行版の資料に基づく候補と未検証のルートは区別し、空欄の情報を推測で埋めません。

変更時は関連する確認を行い、ローカルでコミットします。GitHubへの公開はユーザーが承認した場合に行います。
